# Art Credits

Owner: `graphics-designer`.

## M1: no third-party art
All M1 visuals are **original and procedural**. They are generated at runtime in TypeScript from Three.js primitives
in `src/render/procedural/` (characters, props, weapons, loot, toon materials, outlines). No external model, texture,
font, or icon files are used. The palette and designs are original to this project. See `docs/art/STYLE.md`.

Three.js (MIT licence) is a code dependency, not an art asset. It is listed here only for completeness.
