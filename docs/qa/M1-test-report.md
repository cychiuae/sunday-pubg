## Harness notes
- Every E2E spec starts its own game server + Vite (random ports, HMR off) so edits landing mid-run cannot reload the
  page. The root `playwright.config.ts` (build-engineer) already runs specs this way with no shared webServer.
- Headless limits and workarounds are in TEST_PLAN.md ("Known harness limits"). Two suspected bugs turned out to be
  harness artefacts and were not filed: "a Space tap doesn't jump" (polling started after the jump) and "a 120 ms
  click fires 29 SMG rounds" (mouseup reached the DOM 0.6-1.3 s late).
