# BUG-014: The dev/E2E hook (`window.__game`) exposes no M2c state

- **Severity:** minor (testability; no player impact). E2E has to read M2c state from a spectator socket and the DOM,
  and some client-only behaviour cannot be asserted at all (name tags hidden in smoke, broken-pane rendering, the
  client's layout hash, the predicted throwable / sight).
- **Build:** working tree 2026-11-18 (M2c complete, PROTOCOL_VERSION 4, balance v7).
- **Suspected owner:** game-developer (`src/game/devHook.ts`, `ClientGame.devState()`).

## Steps to reproduce
1. Start any match with `?e2e` (or the Vite dev build) and run `window.__game` in the console.
2. `grep -n "layout\|smoke\|rocket\|pane\|melee\|scope\|level\|throwable" src/game/devHook.ts` -> no M2c fields.

## Expected
The hook covers the milestone's client state, like M2a (stance, ADS, grenades) and M2b (mapId, cameraView, dropPhase,
room) did. For M2c at least: the applied layout (`seed`, `hash`, `version`, `look`, and whether the client's own hash
matched the server's), the held weapon's `level` and effective `sight`, `selectedThrowable` and both throwable counts,
`spareScope`, the melee swing view, `rockets` / `smokes` as drawn (ids and positions), `brokenPanes`, `inSmoke`, and
per remote player `smokeHidden` (the name-tag / outline hiding decision).

## Actual
`DevGameState` stops at the M2b fields. `tests/e2e/m2c.spec.ts` and `tests/e2e/m2c-office.spec.ts` work around it with
the observer socket (server truth) and DOM text; smoke.md 11 / M2C-UI-21..23 (name tag and hit-marker hiding through
smoke in the browser) stay screenshot-only.

## Evidence
`src/game/devHook.ts` (interface `DevGameState`); the M2c specs' header comments.

## Status: closed (fixed), 2026-11-18, M2c closing round
Verified in the browser: `__game.layout` (seed 4821 = 0x12D5, `hashMatched: true`, `clientHash === hash` on both
browsers), `weaponLevel` and `localSlots[0].level` equal the server level, `selectedThrowable`, `throwables`, `smokes`
(id, centre, radius 6.5), `players[].smokeHidden`, `brokenPanes` are present and used by `tests/e2e/m2c.spec.ts`,
`tests/e2e/m2a.spec.ts` and `tests/e2e/m2c-office.spec.ts`. The value of `smokeHidden` is wrong in one case; that is a
separate game bug (BUG-016), not a hook problem.
